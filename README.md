# My Time Fitness

Responsive, single-page static landing website for My Time Fitness in Naini, Prayagraj.

## Stack
- HTML, CSS and vanilla JavaScript (static and compatible with GitHub Pages)
- Google Fonts (Barlow Condensed and Inter)
- Sample photos served by Unsplash
- WhatsApp click-to-chat, click-to-call and Google Maps directions
- GitHub Actions deployment to GitHub Pages

## Local preview
Open `index.html` in a browser, or run a local static server:

```bash
python3 -m http.server 8000
```

Then visit http://localhost:8000.

## Deployment
The workflow at `.github/workflows/deploy.yml` deploys the repository root to GitHub Pages on each push to `main`.

In GitHub, open **Settings → Pages** and choose **GitHub Actions** as the build and deployment source. Then check the **Actions** tab for the deployment status.

## Notes
This is a static marketing site; it does not collect or store visitor information and has no login, booking backend, or payment processing.
